Validador CFDI de Proveedor

Módulo Odoo 18.0 — Localización México

Versión 18.0.1.0.0 l10n_mx_edi_cfdi_validator Depende: l10n_mx_edi, account

¿Qué hace este módulo?

Extiende el flujo de facturas de proveedor en Odoo 18 México con una pestaña CFDI dedicada que lee el XML automáticamente, expone todos sus datos clave y ejecuta validaciones SAT configurables que pueden bloquear la confirmación del documento si fallan.

Alcance: Solo actúa sobre in_invoice (facturas de proveedor) e in_refund (notas de crédito de proveedor). No afecta documentos de cliente.

⚠️ Notas de Implementación

1. Trigger de lectura XML: Los campos CFDI se pueblan automáticamente cuando el usuario adjunta un XML a través del flujo estándar (Pestaña CFDI → Cargar archivo). El override de _l10n_mx_edi_import_cfdi_invoice en account.move captura el evento y llama a _mx_cfdi_populate_all().

2. Facturas existentes: Para facturas que ya tienen CFDI adjunto antes de instalar el módulo, use el botón "Releer XML" que aparece en la pestaña CFDI.

3. Validaciones en tiempo real: Los campos de resultado de validación son computed sin almacenar, por lo que siempre reflejan la configuración actual de la empresa sin necesidad de revalidación manual.

4. Bloqueo condicional: El override de action_post() solo evalúa las validaciones que están activas (True) en la empresa. Las validaciones desactivadas nunca bloquean la confirmación.

5. Estatus SAT: La validación de estatus SAT lee el campo l10n_mx_edi_cfdi_sat_state que ya mantiene el módulo base l10n_mx_edi. Para que esta validación funcione, primero debe haberse consultado el SAT desde la pestaña CFDI estándar.
