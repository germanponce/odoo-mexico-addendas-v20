Addenda AMECE 7.1

Este modulo nos permite trabajra con la Addenda de AMECE 7.1

Overview

Compañia

Debemos ingresar lo datos dentro de la Compañia en la pagina Addenda:
  • Alternate Identification
  • Numero Global de Localizacion


Podemos especificar codigos para cada cliente:
  • Alternate Identification
  • GLN


Factura

Debemos ingresar lo datos para la Addenda:
  • Numero de pedido (comprador)
  • Fecha del Pedido
  • Numero de aprobacion
  • Contacto de Compras
  • Entrega Mercancia

Productos

Debemos capturar:
  • Codigo GTIN para la Addenda AMECE 7.1


Podemos especificar codigos para cada cliente:
  • Codigo GTIN por Cliente


Cliente

Dentro del Cliente seleccionamos la Addenda:
  • Addenda AMECE 7.1


Ingresamos La información:
  • Numero GLN
