PAC Finkok

Este modulo agrega la siguiente funcionalidad:


  • Permite establecer enviar los XML demasiado grandes (Pagos) a un servicio especial.:
    • https://sftpdemo-facturacion.finkok.com/servicios/soap/stamp.wsdl
  • Todo XML que supere el limite se enviara por el nuevo servicio y el limite es determinado por un parametro del sistema llamado:
    • limit_weight_bytes_finkok
      • Limite por defecto: 800,000 Bytes -> 800 Kbs
