Actualizacion y Restriccion de la lista de EFOS y EDOS

Es modulo proporciona un listado de ayudaría a gestionar si dentro del catálogo de clientes y proveedores, existe alguna empresas fraudulentas, con base al listado proporcionado por el SAT.


Para acceder al catalogo de EFOS y EDOS tendremo que posicionarnos en el Menu Contabilidad -> Clientes -> Catalogo EFOS y EDOS.

El Catalogo de EFOS y EDOS tambien es accesible desde el menu de Contactos.






El metodo planificado que se encarga de actualizar el listado de registros de EFOS y EDOS se llama:
  • Sincronización de Listado de EFOS y EDOS con el SAT



Podemos omitir un registro para poderlo seleccionar sin importar su estadus, para ello activamos el campo:
  • No Validar
