Modulo Addendas Base

Este modulo nos permite integrar los datos de una forma ordenada para poder tener controlada la distribución de los extra fields para las Addendas.

Overview

Objetos

Agrega los campos y paginas en las clases:
  • Compañia
  • Productos
  • Clientes
  • Ventas
  • Albaranes
  • Facturas

Herencia

Podemos Heredar cada objeto en las vistas dentro del modulo por ejemplo:
  • Compañia
    • page name="addendas_extra_fits"
