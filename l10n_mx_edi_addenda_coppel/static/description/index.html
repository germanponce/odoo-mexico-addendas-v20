Addenda Coppel

Este modulo nos permite trabajra con la Addenda de Coppel

Overview

Compañia

Debemos ingresar lo datos dentro de la Compañia en la pagina Addenda Coppel:
  • Identificador Proveedor
  • Tipo de proveedor

Productos

Debemos ingresar lo datos para la Addenda Coppel:
  • Código
  • Talla
  • Modelo

Pedidos

Debemos ingresar lo datos para la Addenda Coppel:
  • Num. Pedido
  • Num. Bodega
  • x_name_warehouse
  • x_street_warehouse

Lineas Pedido

Debemos ingresar lo datos para la Addenda Coppel:
  • Prepacant
  • Pallet Quantity

Albaranes

Debemos ingresar lo datos para la Addenda Coppel:
  • Total de lotes

Cliente

El Paso final es la selección de la Addenda en el Cliente:
  • Addenda Coppel
