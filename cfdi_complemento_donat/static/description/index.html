CFDI Complemento - Donaciones

Este modulo permite agregar a las facturas el complemento Donatarias.

CFDI Complemento - Donatarias

Lo primero es activar dentro de nuestro cliente el campo:

  • ★   Complemento - Donatarias


Configuramos los datos en la Compañia:

  • ★   Pestaña Donatarias.


  • ★   Ingresamos Número de Autorización
  • ★   Ingresamos Fecha de Autorización
  • ★   Ingresamos Leyenda

Notas:

Si no queremos en la factura el complemento de donatarias, solo desactivamos el campo en el registro de factura antes de validarlo.
